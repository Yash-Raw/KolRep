### Phase 1: Voice Cloning & Audio Pipeline
- **Implemented**:
  - `AudioService` using `ffprobe` for metadata and `ffmpeg` with `silencedetect` and `volumedetect` to compute speech ratio and clipping.
  - Audio extraction/conversion from video containers (MP4, WebM) to 44.1kHz mono PCM WAV.
  - Storage service (`StorageService`) with S3/R2 presigned URL generator and transparent local filesystem fallback.
  - Abstract `VoiceProvider` and concrete `ElevenLabsProvider` supporting Instant Voice Cloning `POST /v1/voices/add`.
  - `VoiceService` managing voice lifecycle (`upload_pending` -> `cloning` -> `ready` / `failed`), affirmative consent logging in `voice_consents`, and provider voice deletion.
  - REST endpoints: `POST /api/v1/voices`, `GET /api/v1/voices`, `GET /api/v1/voices/{id}`, `PATCH /api/v1/voices/{id}`, `DELETE /api/v1/voices/{id}`.
  - Voice Library UI with multi-step cloning modal (File upload, Quality report, Speaker Consent, Cloning).
- **Files Created**:
  - `backend/app/services/audio_service.py`
  - `backend/app/services/storage_service.py`
  - `backend/app/providers/base.py`, `backend/app/providers/elevenlabs.py`
